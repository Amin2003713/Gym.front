# Local startup and toolchain fixes

- `npm run dev` now starts plain HTTP (`http://localhost:3000`) without experimental `mkcert` certificate installation. HTTPS can be re-enabled manually if required.
- Next.js 16 routing uses `proxy.ts`; this project must not also contain `middleware.ts`.
- ESLint config uses the flat configs exported by `eslint-config-next`, avoiding the legacy `FlatCompat` validation crash under ESLint 9.
- The legacy HR reports/users pages and their old employee fields are not part of this gym-group version; the remaining tenant pages are gym-oriented.

After replacing the project files, run `npm install`, then `npm run dev`, `npm run lint`, and `npx tsc --noEmit`.
